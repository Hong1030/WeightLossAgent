该软件为基于能量平衡原理的桌面智能体，输入用户身体参数与减重目标，自动计算代谢指标，生成个性化运动处方与每日 / 7 天周食谱计划，支持用户喜好反馈调优，JSON 本地持久化存储。

## ✨ Features

- 🧑‍🤝‍🧑多用户档案管理，自动计算 BMI、BMR、TDEE 热量指标
- 🏃运动库管理：增删改查、CSV 导入导出，内置 30 条运动数据
- 🍱食谱库管理：管理早 / 午 / 晚 / 加餐食谱，内置 40 套食谱
- 📋智能运动处方：自动组合运动，严格控制消耗热量区间
- 🥗食谱推荐：全天热量控制在目标 ±10%
- 📅一键生成 7 天周计划，支持导出 TXT/CSV 报告
- 👍👎喜好反馈，反馈结果影响后续推荐
- 💾JSON 持久化，文件损坏自动恢复初始化数据

## 🧮核心公式

Mifflin‑St Jeor 代谢公式，饮食：运动缺口分配 7:3；采用**多次随机采样择优**实现推荐算法。

## 🛠环境

- Windows11
- Qt Creator + Qt 6.11.2 Widgets
- C++17，qmake 构建

## 🚀 Build

1. Clone 仓库，使用 Qt Creator 打开`.pro`工程
2. 配置 Qt6.11.2 编译套件，执行 qmake
3. 编译运行，首次启动自动加载示例数据，存储至`data.json`

## 📂架构分层

- UI 层：Qt Widgets 窗口与对话框
- 业务层：`AgentCore`(核心算法)、`WeeklyPlanManager`(周计划)
- 模型层：`UserProfile` / `Exercise` / `Recipe`
- 存储层：`DataStore` JSON&CSV 读写
